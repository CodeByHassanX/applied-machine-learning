# Stock Price Prediction

This project predicts stock prices using the provided `stock_data.csv` dataset.

## Dataset

- `stock_data.csv` (input data)

## Notebook

- `Stock_Price_Prediction.ipynb`

## Typical Steps

- Load and inspect the dataset
- Perform feature engineering / time-series preprocessing
- Train a forecasting/regression model
- Evaluate prediction quality

## Requirements

- Python 3.x
- Jupyter Notebook/JupyterLab
- Common libraries: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`

## Usage

1. Ensure `stock_data.csv` is in the same directory as the notebook.
2. Open `Stock_Price_Prediction.ipynb` and run cells.
